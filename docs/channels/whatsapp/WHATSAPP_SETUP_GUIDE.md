# Посібник зі створення та оформлення WhatsApp-каналу для SvitloSk Publisher

Цей документ містить аналіз вибору типу ресурсу (Канал проти Групи) та покрокову практичну інструкцію зі створення, брендування та налаштування офіційного каналу журналу в WhatsApp.

---

## 1. Канал чи Група: Що обрати для журналу SvitloSk?

Для публічного сервісу міського журналу знеструмлень вибір є однозначним — **виключно КАНАЛ (WhatsApp Channel)**. 

### Порівняльна таблиця:

| Критерій | WhatsApp Група (Group) | WhatsApp Канал (Channel) — **НАШ ВИБІР** |
| :--- | :--- | :--- |
| **Кількість підписників** | Обмежено: максимум **1024 особи** | **Необмежено** (тисячі й десятки тисяч людей) |
| **Конфіденційність номерів** | ❌ **Критична загроза:** Усі учасники бачать номери телефонів одне одного | ✅ **100% анонімність:** Номери телефонів підписників та адміна надійно приховані |
| **Формат сповіщень** | Багатосторонній чат (ризик спаму, флуду, несанкціонованих дзвінків) | **Односторонній broadcast:** Публікує лише паблішер, підписники лише читають |
| **Зручність читання** | Повідомлення перемішуються з репліками учасників | Чиста стрічка журналу (місто, округи, графіки) |
| **Пошук та приєднання** | Тільки через запрошення або додавання за номером | Публічне посилання (`whatsapp.com/channel/...`) та пошук у каталозі |

> [!CAUTION]
> Використовувати **Групу** для міського журналу категорично заборонено через порушення приватності: якщо в групу зайде 500 жителів міста, їхні номери телефонів стануть відкритими для спамерів, шахраїв та рекламних розсилок. **Канал гарантує повну безпеку контактів громадян.**

## 2. Покрокова інструкція: Як створити WhatsApp-канал

Створити канал можна як зі смартфона (Android / iOS), так і з комп'ютера (WhatsApp Web або Desktop).

### Крок 2.1. Перехід до розділу каналів
1. Відкрийте WhatsApp.
2. Перейдіть на вкладку **«Оновлення» (Updates)** — вона розташована поруч із «Чатами» (у старих версіях називалася «Статус»).
3. Прокрутіть униз до розділу **«Канали» (Channels)**.
4. Натисніть на значок **`+`** праворуч від напису «Канали».
5. У меню оберіть пункт **«Створити канал» (Create Channel)**.

### Крок 2.2. Підтвердження умов
1. З'явиться вікно з правилами:
   - Будь-хто може знайти ваш канал.
   - Люди бачать ваш канал, але не бачать ваш номер телефону чи профіль.
   - Ви несете відповідальність за свій канал.
2. Натисніть **«Продовжити» (Continue)**.

### Крок 2.3. Введення назви, аватарки та опису
1. **Назва каналу:** введіть офіційну назву (див. розділ 3 з рекомендаціями).
2. **Аватарка:** натисніть на значок камери та завантажте логотип.
3. **Опис:** додайте лаконічний опис призначення каналу.
4. Натисніть кнопку **«Створити канал» (Create Channel)**.

Канал готовий до роботи!

## 3. Рекомендації з оформлення та брендування каналу

Оформлення має бути впізнаваним, офіційним та узгодженим із брендом **SvitloSk** у Telegram та Facebook.

### 3.1. Назва каналу (Channel Name)
* **Рекомендований варіант:** `SvitloSk | Журнал знеструмлень`
* **Альтернативний варіант:** `Світло Старокостянтинів | SvitloSk`
*(Стисло, впізнавано в пошуку, чітко вказує на призначення).*

### 3.2. Аватарка каналу (Profile Picture)
* **Зображення:** Фірмовий логотип SvitloSk (жовта лаконічна лампа або графічний символ проекту на контрастному темно-синьому чи чорному фоні).
* **Формат:** Квадратний (рекомендований розмір `500x500` або `800x800` пікселів, без дрібного тексту, який важко читати в круглому міні-вікні чату).

### 3.3. Опис каналу (Channel Description)
Скопіюйте та вставте наступний текст опису:

```
Офіційний журнал знеструмлень Старокостянтинівської міської територіальної громади від проекту SvitloSk.

Автоматичні та оперативні сповіщення:
• Планові відключення електроенергії по місту та 13 округах
• Аварійні знеструмлення та ремонтні роботи
• Прогноз відключень на завтра
• Погодинні графіки підчерг

Веб-додаток: svitlosk.online
```

## 4. Обов'язкові налаштування каналу

Після створення відкрийте налаштування каналу (натисніть на назву каналу вгорі):

1. **Реакції на повідомлення (Channel Settings ➡️ Reactions):**
   - **Рекомендовано:** вибрати **«Будь-які емодзі» (Any emoji)** або **«Стандартні емодзі»**. 
   - Це дозволяє читачам ставити реакції (наприклад, 👍 або 💡), але виключає текстовий спам чи суперечки.

2. **Отримання публічного посилання (Channel Link):**
   - Натисніть **«Посилання на канал» (Forward link / Copy link)**.
   - Посилання має вигляд: `https://whatsapp.com/channel/0029VaXXXXXXXXXX`.
   - Збережіть це посилання — саме за ним підписуватимуться мешканці громади.

3. **Ідентифікатор каналу для Паблішера:**
   - Кожен канал WhatsApp має свій унікальний числовий/буквений ID у посиланні або в Meta Business Platform, який надалі буде внесений у змінну оточення `WHATSAPP_CHANNEL_ID`.
