# Покрокова інструкція: Підключення Facebook-каналу до SvitloSk Publisher

Цей посібник містить повну інструкцію для створення Facebook-сторінки, реєстрації технічного застосунку Meta App та генерації **безстрокового токена доступу (Permanent Long-Lived Page Access Token)** для автоматичної публікації повідомлень паблішером.

---

## 1. Створення Facebook-сторінки (Page)

1. Відкрийте [facebook.com/pages/create](https://www.facebook.com/pages/create).
2. Заповніть дані:
   - **Назва сторінки:** наприклад, `Світло Старокостянтинів` або `SvitloSk Моніторинг`.
   - **Категорія:** `Комунальна служба`, `Місцева служба` або `Інформаційно-довідковий сайт`.
   - **Опис:** Коротка інформація про оперативне сповіщення про відключення світла.
3. Натисніть **Створити сторінку**.
4. Скопіюйте **Page ID (Ідентифікатор сторінки)**:
   - Перейдіть на створену сторінку.
   - Відкрийте розділ **«Про сторінку» (About)** ➡️ **«Прозорість сторінки»** або в налаштуваннях.
   - Page ID — це число з 15–16 цифр (наприклад, `105829184729104`).

---

## 2. Реєстрація технічного застосунку (Meta App)

Meta App виступає технічним клієнтом, через який наш C# паблішер спілкується з серверами Meta.

1. Перейдіть на портал [developers.facebook.com](https://developers.facebook.com).
2. Увійдіть у свій Facebook-акаунт та підтвердьте профіль розробника (якщо ще не зареєстровані).
3. У верхньому правому кутку натисніть **My Apps** ➡️ **Create App** (Створити застосунок).
4. Виберіть тип застосунку:
   - **What do you want your app to do?** ➡️ Виберіть **Other** (Інше) ➡️ **Next**.
   - **Select an app type** ➡️ Виберіть **Business** (Бізнес) ➡️ **Next**.
5. Заповніть інформацію:
   - **App Name (Назва застосунку):** `SvitloSk Publisher` (або `SvitloSk`).
   - **App Contact Email:** вкажіть вашу пошту.
6. Натисніть **Create App**.

> [!TIP]
> У налаштуваннях створеного застосунку (**Settings ➡️ Basic**) ви можете вказати посилання на ваш діючий PWA-додаток у полях **App Domains** та **Website URL**.

---

## 3. Генерація безстрокового токена (Permanent Page Access Token)

Звичайні токени користувача діють лише 1–2 години. Для 24/7 автономної роботи паблішера потрібен **безстроковий токен сторінки (Page Access Token з терміном дії "Never")**.

### Крок 3.1. Початковий токен у Graph API Explorer
1. Відкрийте інструмент [developers.facebook.com/tools/explorer](https://developers.facebook.com/tools/explorer).
2. У правому блоці перевірте:
   - **Meta App:** вибрано ваш застосунок (`SvitloSk Publisher`).
   - **User or Page:** вибрано `User Token`.
3. У полі **Permissions** додайте три обов'язкові дозволи:
   - `pages_show_list`
   - `pages_read_engagement`
   - `pages_manage_posts`
4. Натисніть синю кнопку **Generate Access Token**.
5. У спливаючому вікні виберіть вашу створену сторінку та дозвольте керування публікаціями.
6. Скопіюйте згенерований короткотривалий токен з поля **Access Token**.

### Крок 3.2. Продовження токена (Long-Lived Token)
1. Відкрийте інструмент [Access Token Debugger](https://developers.facebook.com/tools/debug/accesstoken).
2. Вставте скопійований токен і натисніть **Debug**.
3. Унизу таблиці натисніть кнопку **Extend Access Token** (Продовжити токен).
4. Скопіюйте згенерований 60-денний токен.

### Крок 3.3. Отримання безстрокового токена сторінки (Never-expiring)
1. Поверніться у [Graph API Explorer](https://developers.facebook.com/tools/explorer).
2. Вставте 60-денний токен у поле **Access Token**.
3. У полі адреси запиту введіть:
   ```http
   GET me/accounts
   ```
4. Натисніть кнопку **Submit**.
5. У JSON-відповіді знайдіть блок вашої сторінки:
   ```json
   {
     "data": [
       {
         "id": "105829184729104",
         "name": "Світло Старокостянтинів",
         "access_token": "EAAG...ваш_безстроковий_токен...",
         ...
       }
     ]
   }
   ```
6. Скопіюйте значення поля `"access_token"`. Цей токен є **безстроковим** і діятиме постійно.

---

## 4. Збереження секретів у системі паблішера

Після отримання `Page ID` та `access_token` запустіть скрипт конфігурації у PowerShell:

```powershell
.\deploy\set-facebook-secrets.ps1
```

Введіть:
1. `Facebook Page ID`
2. `Facebook Page Access Token` (введення маскується)
3. Шлях до реєстру (за замовчуванням: `local/registry/facebook_registry.json`)

---

## 5. Перевірка підключення

Перевірте зв'язок із Facebook через вбудовану діагностичну команду:

```powershell
dotnet run --project SvitloSk.Publisher.Infrastructure -- --facebook-check
```

Очікуваний результат:
```
[SUCCESS] Connected to Page 'Світло Старокостянтинів' (ID: 105829184729104)
```

Після цього Facebook-канал автоматично синхронізуватиметься у фоновому демоні поруч із Telegram-каналом з повною ізоляцією помилок.
