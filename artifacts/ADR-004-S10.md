# ADR-004-S10: S-10 Technical Information Expired is Blocked

## Context
During Phase A implementation of the Minimal Situation Model, the task mandated implementing detection for S-10 (Technical Information Expired).

According to the normative Situation Detection Matrix, S-10 is defined as:
- **Condition**: Technical information must be updated every 24 hours.
- **Properties**: Requires comparing `Publication.CreatedAt` against the current timestamp.

## Blocker
The existing domain object `SvitloSk.Publisher.Domain.Publication` is implemented as:
`public record Publication(Guid Id, string TerritoryId, string Content, PublicationClassification Classification);`

It completely lacks a `CreatedAt` or equivalent timestamp property. 

## Resolution Attempt
To implement S-10, I would need to modify the `Publication` domain object and its surrounding lifecycles to introduce a `CreatedAt` property. However, this violates the strict directive: "Do NOT implement publication structural extensions" and "Do not invent architecture". 

## Decision
Implementation of S-10 has been halted. The situation remains blocked pending an architectural decision on how to track publication age in the Domain layer.
